# Безопасность и персональные данные

## Реализовано в версии 1

| Требование | Как сделано |
|---|---|
| Разграничение прав на сервере | Каждая операция проверяет разрешение роли (`app/permissions.py`). Интерфейс только скрывает кнопки. |
| Разделение администратора и клиента | Разные зоны сессий и cookie (`ic_admin_session` / `ic_client_session`); сессия покупателя не принимается админскими маршрутами. |
| Защита от доступа к чужим договорам | Все маршруты кабинета фильтруют по `client_id` из сессии; чужой и несуществующий договор дают одинаковый ответ 404. |
| Защищённая авторизация | Пароли — Argon2; в cookie случайный токен, в базе только его SHA-256; cookie `HttpOnly`, `SameSite=Lax`, `Secure` при HTTPS. |
| Второй фактор | TOTP для сотрудников. Для владельца обязателен при `ENVIRONMENT=production` (`REQUIRE_OWNER_2FA`): без него открывается только настройка. |
| Защита от перебора | 5 неудачных попыток на логин или 20 с одного IP за 15 минут → блокировка (хранится в базе, переживает перезапуск). |
| CSRF | Изменяющие запросы принимаются только с разрешённых Origin; сайты обращаются к API через собственный прокси. |
| Маскирование | Паспорт, адрес, телефон скрыты от ролей без права `clients.pd`; в журнал пишутся названия изменённых полей, а не значения. |
| Журнал действий | `audit_log`: кто, что, когда, с какого IP. Записи только добавляются. |
| Закупочная цена | Не попадает в публичный API; от менеджера скрыта правом `cars.cost`. |
| Файлы | Проверка сигнатуры (JPEG/PNG/WebP), лимит размера, случайные имена, хранение вне веб-корня; публично отдаются только фото опубликованных автомобилей. |
| Антиспам заявок | Скрытое поле-ловушка и лимит 10 заявок в час с одного IP (хранится хеш IP, не сам адрес). |
| Секреты | Только в `.env` вне git; в репозитории — `.env.example` без значений. |
| Сообщения клиентам | Только на подтверждённые контакты, только при согласии на канал; время и частота по политике; журнал всех сообщений. |
| Документы | Покупатель видит только утверждённые и подписанные документы своих договоров; подписанный документ неизменяем, скан хранится с SHA-256. |
| Резервные копии | Ежедневно база (pg_dump) и файлы, хранение 30 дней, еженедельная проверка архива и (по настройке) полного восстановления. |

## Обязательно до работы с реальными данными

1. **Локализация (152-ФЗ).** Сервер и база с персональными данными граждан РФ — в дата-центре на территории РФ.
   Резервные копии — тоже в РФ.
2. **Уведомление Роскомнадзора** об обработке персональных данных, политика обработки и тексты согласий —
   подготовить и утвердить с юристом (в коде сейчас черновики, версия согласия `2026-11-draft`).
3. **HTTPS.** Обратный прокси (nginx/Caddy) с сертификатом; `COOKIE_SECURE=true`, `ENVIRONMENT=production`,
   `ALLOWED_ORIGINS` — только реальные домены.
4. **Второй фактор владельца** — включить сразу после первого входа.
5. **Резервное копирование.** Выполняет фоновый обработчик (версия 2). Том `backups` держите на отдельном диске
   и регулярно копируйте за пределы сервера (в РФ). Для полной проверки восстановления задайте
   `BACKUP_VERIFY_DATABASE_URL` — отдельную пустую базу.
6. **Доступ к серверу** — только по ключам SSH, порты 5433/8000/3000/3001 не публикуются наружу (в `docker-compose.yml`
   они привязаны к `127.0.0.1`).
7. **Внешние ИИ-сервисы** — реальные персональные данные не передаются без правового основания и проверки безопасности.

## Резервная копия вручную (PowerShell + Docker)

```powershell
$stamp = Get-Date -Format "yyyyMMdd-HHmm"
# Дамп создаётся внутри контейнера и копируется файлом: перенаправление «>» в PowerShell 5.1 портит двоичные данные
docker compose exec -T db pg_dump -U islamcar -Fc -f /tmp/backup.dump islamcar
docker compose cp db:/tmp/backup.dump "backup-$stamp.dump"

# Проверка восстановления в отдельную базу
docker compose cp "backup-$stamp.dump" db:/tmp/restore.dump
docker compose exec -T db createdb -U islamcar islamcar_restore_check
docker compose exec -T db pg_restore -U islamcar -d islamcar_restore_check /tmp/restore.dump
docker compose exec -T db psql -U islamcar -d islamcar_restore_check -c "select count(*) from contracts"
docker compose exec -T db dropdb -U islamcar islamcar_restore_check
```

Файлы `*.dump` и папка `backups/` исключены из git.
