# Шаблоны документов (версия 2)

Здесь будут **утверждённые** шаблоны: договор купли-продажи автомобиля с оплатой в рассрочку, график платежей,
акт приёма-передачи, проекты договоров залога и поручительства, предварительное соглашение, дополнительное соглашение
об изменении графика, уведомления о сроке оплаты и о просрочке, акт сверки, подтверждение полного исполнения.

Правила:

- шаблон попадает в эту папку только после утверждения квалифицированным российским юристом (дата и версия — в имени файла);
- в шаблоне — только поля для подстановки из проверенных карточек клиента, автомобиля и договора; случайные реквизиты запрещены;
- система не создаёт подписи, печати и не отмечает документ как нотариально удостоверенный без подтверждения реального действия;
- реальные заполненные договоры в репозиторий не кладутся — они хранятся в защищённом хранилище сервера.
