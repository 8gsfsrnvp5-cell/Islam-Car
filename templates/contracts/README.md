# Шаблоны документов

Каждый шаблон — папка `<code>/` с `meta.json` (название, версия, обязательные данные, параметры, видимость покупателю)
и `template.md` (текст с подстановками Jinja2 и простой разметкой — см. `services/api/app/documents/markup.py`).

**Все 12 шаблонов — черновики версии 0.1** и требуют утверждения квалифицированным российским юристом.

- Пометки `[[ЮРИСТ: …]]` — вопросы, которые юрист решает прямо в тексте. Пока они есть, шаблон нельзя утвердить.
- Утверждение фиксируется в админке («Документы и шаблоны» → «Шаблоны») и привязано к SHA-256 содержимого:
  любое изменение файлов снимает утверждение. После правки повысьте `version` в `meta.json`.
- Документы из неутверждённого шаблона — проекты с водяным знаком; зафиксировать их подписание как окончательных нельзя.
- В шаблоне — только поля из проверенных карточек; если данных нет, документ не формируется, а система называет,
  чего не хватает.
- Система не создаёт подписи и печати и не отмечает документ как нотариально удостоверенный.
- Заполненные договоры в репозиторий не кладутся — они хранятся в базе и защищённом хранилище сервера.

| Код | Документ |
|---|---|
| `sale_contract` | Договор купли-продажи автомобиля с оплатой в рассрочку |
| `payment_schedule` | График платежей (приложение) |
| `acceptance_act` | Акт приёма-передачи |
| `pledge_draft` | Проект договора залога |
| `guarantee_draft` | Проект договора поручительства |
| `preliminary_agreement` | Предварительное соглашение о покупке |
| `schedule_addendum` | Дополнительное соглашение об изменении графика |
| `due_notice` | Уведомление о приближении срока оплаты |
| `overdue_notice` | Уведомление о просроченном платеже |
| `reconciliation_act` | Акт сверки расчётов |
| `completion_confirmation` | Подтверждение полного исполнения обязательств |
| `notary_pledge_sheet` | Сведения для нотариуса: уведомление о залоге |
