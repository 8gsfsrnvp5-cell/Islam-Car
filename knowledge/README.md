# Библиотеки знаний (версия 3)

Здесь будут структурированные правила, на которые опираются юридический, бухгалтерский агенты и агент исламского
финансирования. В версии 1 библиотеки **не заполнены намеренно**: правила не пишутся по памяти или по предположению ИИ —
каждое добавляется с официальным источником и проходит проверку специалиста.

| Папка | Содержание | Кто подтверждает |
|---|---|---|
| `legal/` | ГК РФ (купля-продажа в рассрочку, исполнение обязательств, залог, поручительство), нотариат, защита прав потребителей, 230-ФЗ, 152-ФЗ, 63-ФЗ, партнёрское финансирование, судебная практика | квалифицированный российский юрист |
| `accounting/` | НК РФ, разъяснения ФНС, ФСБУ, правила ККТ, режимы налогообложения | бухгалтер / налоговый консультант |
| `islamic-finance/` | мурабаха и смежные принципы | уполномоченный специалист по шариату |

## Формат записи

Одна запись — один файл `*.json` (поля обязательны, если не указано иное):

```json
{
  "id": "legal.gk.sale-installments",
  "title": "Краткое название правила",
  "act": "Полное название нормативного акта",
  "article": "статья, пункт",
  "source_url": "ссылка на официальную публикацию (pravo.gov.ru, сайт ведомства, суда)",
  "effective_from": "ГГГГ-ММ-ДД",
  "effective_to": null,
  "last_checked": "ГГГГ-ММ-ДД",
  "scope": ["individual_one_off", "ip", "llc", "consumer"],
  "summary": "Своими словами, без копирования закрытых коммерческих баз",
  "review": { "status": "not_reviewed | approved | rejected", "by": null, "date": null },
  "supersedes": null
}
```

Правила поиска для агентов:

- берётся редакция, действовавшая на дату договора (`effective_from` ≤ дата < `effective_to`);
- запись со статусом проверки, отличным от `approved`, показывается с пометкой «не проверено специалистом»;
- если `last_checked` старше 180 дней — предупреждение об устаревании;
- если подходящей записи нет — ответ «Требуется проверка юриста» (бухгалтера, специалиста по шариату).

Источники: официальные публикации нормативных актов, сайты государственных органов, Банка России, ФНС, нотариата,
официально опубликованные судебные акты. Материалы закрытых коммерческих правовых баз без лицензии не копируются.
