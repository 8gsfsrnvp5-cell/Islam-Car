# Агенты — версия 3 ✅

Код — `services/api/app/agents` (общие модели, права и сервисы сервера). Запуск — вручную из «Центра ИИ-агентов»
или ежедневно фоновым обработчиком в 07:00 по времени компании.

| Агент | Что делает | Может |
|---|---|---|
| Платёжный | несверенные «Я оплатил», просрочки, согласованность договоров | задачи |
| Уведомлений | нет разрешённого канала при просрочке, сбои доставки, состояние обработчика | задачи |
| Юридический | нормы шаблонов: редакция, источник, статус проверки юристом | только выводы |
| Бухгалтерский | профиль, утверждённые параметры, налоговый календарь, оценка налога | задачи |
| Финансовый | свободные деньги, резерв, достаточность поступлений | только выводы |
| Автомобилей | проверочный лист, VIN и документы, фото, долгие закупки, источник покупки для НДС | задачи |
| Заявок | заявки без ответа, дубли, автомобили под заказ из каталога | задачи |
| Управленческий | ежедневная сводка владельцу | уведомления |

Принципы:

- проверяемые правила без языковой модели: суммы, сроки и нормы — только из данных системы и библиотек знаний;
- чтение через сессию, которая в конце откатывается, — агент не может изменить договор, платёж или статус;
- действия выполняются только через контекст по выданным правам и записываются в журнал запуска;
- выводы содержат ссылки на нормы библиотек; без надёжного основания — «Требуется проверка»;
- персональные данные не передаются внешним ИИ-сервисам.
