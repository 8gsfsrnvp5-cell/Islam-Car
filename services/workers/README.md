# Фоновые задачи и уведомления (версия 2)

В версии 1 уведомления внутренние: сервер API создаёт их синхронно (новая заявка, подтверждённый платёж, ответ на обращение),
и они видны в админке и личном кабинете. Наружу (SMS, e-mail, мессенджеры) ничего не отправляется.

План версии 2 — Celery + Redis:

- расписание напоминаний настраивается в админке (за 5 дней, за 1 день, в дату платежа, после просрочки, после оплаты);
- перед каждой отправкой — повторная проверка остатка по `compute_ledger`, отмена при оплате;
- часовой пояс клиента, допустимое время и частота взаимодействия по 230-ФЗ для просроченной задолженности физлиц;
- только подтверждённые каналы и согласия клиента; рекламные рассылки — отдельное согласие;
- идемпотентность (ключ: договор + строка графика + тип сообщения), журнал отправок, повторы при техническом сбое,
  уведомление администратора о неудачных попытках связи;
- сведения о долге не отправляются посторонним и на неподтверждённые адреса.
