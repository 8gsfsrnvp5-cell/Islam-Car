# Фоновые задачи и уведомления — версия 2 ✅

Обработчик работает из кода сервера: `services/api/app/worker` (общие модели и проверки), запуск —
`python -m app.worker` или сервис `worker` в Docker Compose. Обоснование очереди в PostgreSQL —
в [docs/roadmap.md](../../docs/roadmap.md), устройство — в [docs/architecture.md](../../docs/architecture.md).

Что делает:

- планирует напоминания по правилам (до платежа, в день платежа, после просрочки, после оплаты);
- перед отправкой пересчитывает долг, проверяет согласие, подтверждённый контакт, время и частоту по политике;
- отправляет через подключённый канал, повторяет при сбое, ведёт журнал, сообщает сотрудникам о неудачной связи;
- создаёт задачи по срокам (просрочки, залоги, полисы, документы на утверждении);
- делает резервные копии и проверяет восстановление.

Официальный SMS-поставщик не подключён: для этого нужен договор с оператором рассылок и ключи в настройках сервера.
