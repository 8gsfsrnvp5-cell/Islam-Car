# Библиотеки знаний

Нормы и принципы, на которые опираются документы, налоговые расчёты, проверки мурабахи и агенты.

| Папка | Записей | Кто подтверждает |
|---|---|---|
| `legal/records.json` | 24 | квалифицированный российский юрист |
| `accounting/records.json` | 17 | бухгалтер / налоговый консультант |
| `islamic-finance/records.json` | 8 | уполномоченный специалист по исламскому финансированию |

**Ни одна запись не проверена.** Это указатели на нормы с кратким изложением своими словами, а не тексты законов.
Даты действия, точные ссылки на официальные публикации и даты сверки не заполнены намеренно — их вносит специалист.

## Формат записи

```json
{
  "code": "legal.gk.489",
  "version": "1",
  "title": "Оплата товара в рассрочку",
  "act": "Гражданский кодекс Российской Федерации (часть вторая) от 26.01.1996 № 14-ФЗ",
  "article": "ст. 489",
  "topics": ["installment_sale"],
  "scope": ["individual_one_off", "ip", "llc"],
  "summary": "Своими словами, без копирования закрытых коммерческих баз",
  "source_url": "точная ссылка на официальную публикацию",
  "source_hint": "как найти акт на официальном портале",
  "effective_from": "ГГГГ-ММ-ДД",
  "effective_to": null,
  "last_checked": "ГГГГ-ММ-ДД",
  "check": "код автоматической проверки (для мурабахи)"
}
```

## Как работает проверка

- Новая редакция нормы — новая запись с тем же `code` и следующим `version` и своими датами действия.
  Для договора берётся редакция, действовавшая на дату договора.
- Запись надёжна, только если: есть заключение специалиста по точному содержимому (SHA-256), заполнены даты,
  есть точная ссылка на публикацию и сверка не старше 180 дней. Иначе — «Требуется проверка …».
- Заключения фиксируются в админке («Библиотеки знаний»), а сама запись правится в репозитории; любое изменение
  записи снимает заключение.
- Источники: официальные публикации нормативных актов, сайты государственных органов, Банка России, ФНС, нотариата,
  официально опубликованные судебные акты; для исламского финансирования — стандарты AAOIFI. Материалы закрытых
  коммерческих правовых баз без лицензии не копируются. Судебная практика добавляется только со ссылкой на официально
  опубликованный акт.
