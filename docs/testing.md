# Тестирование

Автотесты API: `services/api/tests` (pytest). По умолчанию — SQLite в памяти; в CI и по `TEST_DATABASE_URL` — PostgreSQL.
Тестовая база изолирована: тесты отказываются работать с PostgreSQL-базой без `test` в имени. Внешние каналы в тестах —
в режиме «log»: сообщения пишутся в журнал, наружу ничего не уходит. Денежные функции веб-части:
`packages/shared/src/money.test.ts`.

## Ручная проверка версии 5

Через локальный сервер: загрузка трёх фото с координатами съёмки в EXIF → в каталоге они без метаданных, выбранное
главное фото первое, карточка опубликована. Каталог на телефоне (375 px): стрелки и пролистывание пальцем, без
горизонтальной прокрутки. Распознавание на реальном ключе не проверялось.

## Ручная проверка версии 4 в браузере

Банковские выписки: загрузка тестовой выписки (3 документа, 2 входящих) → предложен договор с объяснением, второе
поступление — «договор не найден» → «Учесть платёж» и «Не относится» с причиной → платёж в журнале с источником
«Банковская выписка». Кабинет покупателя: «Оплатить онлайн» в тестовом режиме → страница статуса → «Оплатить (тест)» →
«Оплата получена». Аналитика: графики, подсказка по месяцу, прогноз. Проверка документов, помощник (выключен без ключа),
новые роли в настройках, XLSX-выгрузки.

## Ручная проверка версии 2 в браузере

Новые окна меню → договор: формирование «Графика платежей» и «Договора купли-продажи» из шаблонов (подсветка вопросов
юристу, водяной знак проекта) → реестр шаблонов → карточка клиента: подтверждение телефона и согласие на SMS →
подтверждение платежа → журнал сообщений: в кабинет — доставлено, SMS — тестовый режим на маскированный номер,
e-mail — «нет согласия» → настройки: резервная копия и проверка выполнены фоновым обработчиком.
