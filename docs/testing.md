# Тестирование

Автотесты API: `services/api/tests` (pytest). По умолчанию — SQLite в памяти; в CI и по `TEST_DATABASE_URL` — PostgreSQL.
Тестовая база изолирована: тесты отказываются работать с PostgreSQL-базой без `test` в имени.
Денежные функции веб-части: `packages/shared/src/money.test.ts`.

## Ручная проверка в браузере (выполнена при подготовке версии 1)

Настройки продавца → автомобиль через форму → публикация → карточка на сайте и калькулятор (50 000 ₽ × 20) →
заявка → всплывающее уведомление в админке → статус «В работе» → клиент из заявки → реквизиты и проверка личности →
черновик договора с проверками → подписание (№ IC-2026-0001) → ссылка активации → вход покупателя → «Я оплатил» →
подтверждение платежа по сообщению → остаток 1 000 000 ₽ одинаково в кабинете и в админке → главная панель → поиск по VIN.
