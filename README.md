# Islamic Car

Цифровая платформа продажи автомобилей с оплатой по графику по модели мурабахи: продавец покупает автомобиль
в собственность и продаёт его покупателю по заранее установленной окончательной цене. Проценты за рассрочку,
пени и штрафы за просрочку не начисляются.

Два приложения работают через один сервер и одну базу данных:

| Часть | Папка | Порт | Назначение |
|---|---|---|---|
| Клиентский сайт | `apps/client` | 3000 | каталог, заявка, заказ автомобиля, статус заявки, личный кабинет |
| Администрирование | `apps/admin` | 3001 | 15 окон управления: заявки, клиенты, автомобили, договоры, платежи, финансы… |
| Сервер API | `services/api` | 8000 | бизнес-логика, права доступа, расчёты (FastAPI + PostgreSQL) |
| Фоновый обработчик | `services/api/app/worker` | — | напоминания, контроль сроков, резервные копии |
| Шаблоны документов | `templates/contracts` | — | черновики, требуют утверждения юристом |
| Общий код | `packages/shared` | — | типы, подписи статусов, денежные функции |

## Что работает в версии 1

Сквозной путь проверен вручную в браузере и автотестами:

**автомобиль в админке → публикация в каталоге → заявка с сайта → мгновенно у администратора → клиент → договор и график →
доступ в личный кабинет → «Я оплатил» → подтверждение платежа сотрудником → пересчёт остатка в кабинете и на главном экране**

- Реестр автомобилей: собственность / в процессе закупки, публикация, фото, закупочная цена скрыта от публики.
- Заявки с сайта и заказы «под заказ», статус заявки по секретной ссылке, уведомление владельцу без перезагрузки страницы.
- Клиенты (физлица, ИП, ООО), проверка личности, маскирование персональных данных по ролям.
- Договор: проверки перед подписанием (собственность продавца, VIN, реквизиты, арифметика), фиксированный график, номер.
- Платежи: учитываются только после подтверждения сотрудником; «Я оплатил» — только сообщение; сторно с сохранением истории.
- Просрочка считается без начислений; главный экран разделяет договорной объём, деньги, долг, наценку и оценку результата.
- Личный кабинет: договор, график, история оплат, выписка и график в CSV, обращения (чат с менеджером), уведомления.
- Календарь поступлений, расходы и результат по каждому автомобилю, отчёты CSV, глобальный поиск.
- Безопасность: серверные сессии, роли, второй фактор (TOTP), защита от перебора паролей, журнал действий.

## Что добавлено в версии 2

- Фоновый обработчик: автоматические напоминания по настраиваемому расписанию с журналом, защитой от повторов,
  проверкой долга перед отправкой, согласиями, подтверждёнными контактами, временем и частотой по 230-ФЗ.
- Конструктор документов: 12 черновых шаблонов, запрос недостающих данных, проверки, подсветка вопросов юристу,
  утверждение, PDF и DOCX, неизменяемая подписанная версия.
- Дополнительные соглашения об изменении графика без изменения цены, история графиков.
- Реестр залогов и полисов, задачи и контроль сроков, резервное копирование с проверкой восстановления,
  обязательный второй фактор для владельца в production.

## Что добавлено в версии 3

- Библиотеки знаний (юридическая, бухгалтерская, исламского финансирования) с честными статусами проверки,
  редакциями на дату и заключениями специалистов; нормы видны в проверках каждого документа.
- Бухгалтерский модуль: налоги только по утверждённым параметрам с источниками — с шагами расчёта и основаниями;
  журнал операций, налоговый календарь.
- Финансовый резерв и свободные деньги, сценарии-прогнозы, рентабельность по реальным договорам.
- Проверочный лист автомобиля до покупки по законным источникам, проверка договора на принципы мурабахи.
- 8 агентов с ограниченными правами и журналом: выводы со ссылками на нормы, задачи сотрудникам, ежедневная сводка.

## Что добавлено в версии 4

- Банковские выписки (формат обмена с 1С): загрузка, защита от повторов, предложенный договор с объяснением;
  долг уменьшается только после подтверждения сотрудником.
- Онлайн-оплата из кабинета (ЮKassa или тестовый режим): платёж учитывается только после проверки статуса сервером.
- SMS через SMS.ru (по договору с оператором), аналитика с графиками и прогнозом, выгрузки XLSX.
- Автоматическая проверка документов и агент документов; роли юриста, специалиста по исламскому финансированию, аудитора.
- Помощник по нормам на Claude API: выключен по умолчанию, получает только записи библиотек и вопрос без персональных данных.

## Что добавлено в версии 5 (фото автомобилей)

- Снимок автомобиля прямо камерой телефона из админки; выбор главного фото для каталога.
- При загрузке фото пересохраняется без метаданных: место съёмки и модель телефона в каталог не попадают.
- Распознавание по фото на Claude API: марка, модель, кузов, цвет, годы выпуска поколения подставляются в карточку
  как подсказка, сотрудник проверяет и указывает цену. Выключено по умолчанию, включает владелец.
- «Сразу опубликовать в каталоге» при создании карточки; галерея на сайте листается пальцем.
- Админка удобна на телефоне: меню открывается кнопкой, формы в одну колонку.

## Быстрый запуск (Windows PowerShell, Docker Desktop)

```powershell
git clone https://github.com/8gsfsrnvp5-cell/Islam-Car.git
cd Islam-Car
Copy-Item .env.example .env        # затем откройте .env и задайте POSTGRES_PASSWORD
docker compose up -d --build
docker compose exec api python -m scripts.create_owner --login owner@example.ru --name "Фамилия Имя"
```

Откройте http://localhost:3001 (админка) и http://localhost:3000 (сайт). Запуск без Docker и подробности —
в [docs/run-windows.md](docs/run-windows.md).

## Демо-стенд в браузере (GitHub Codespaces)

Чтобы показать систему без своего компьютера и сервера: **Code** → **Codespaces** → **Create codespace on main**.
Через 5–10 минут в терминале появятся две ссылки (сайт и админка), логин и пароль. Только тестовые данные:
SMS и письма не отправляются, оплата тестовая. Codespace засыпает, если с ним никто не работает, поэтому
стенд подходит для показа на встрече, а не для круглосуточной работы. Подробно —
в [docs/codespaces.md](docs/codespaces.md).

## Важно

- Репозиторий публичный: здесь нет и не должно быть персональных данных, реальных договоров, банковских реквизитов,
  паролей и ключей. Реквизиты продавца вносятся в базу через раздел «Настройки».
- Юридические тексты (согласие на обработку данных, договоры) — черновики. Перед запуском их должен утвердить
  квалифицированный российский юрист, а соответствие шариату — уполномоченный специалист.
