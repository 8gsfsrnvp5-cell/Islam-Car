# ИИ-агенты (версия 3)

Агенты: платёжный, уведомлений, юридический, бухгалтерский, финансовый, агент автомобилей, агент заявок, управленческий.

Принципы, заложенные уже в версии 1:

- агент вызывает те же сервисные функции и проходит те же проверки прав, что и API; отдельного доступа к базе нет;
- суммы, сроки, остатки считает детерминированный код (`services/api/app/services`), языковая модель не вычисляет деньги;
- юридические и бухгалтерские ответы — только через библиотеки `knowledge/*` со ссылками на основания;
  нет источника, он устарел или противоречит другому — вопрос передаётся на ручную проверку;
- проверочный лист автомобиля перед покупкой заполняется только из законных подключённых источников или сотрудником
  с указанием источника;
- каждое действие агента пишется в журнал; персональные данные не передаются внешним ИИ-сервисам без правового основания.
